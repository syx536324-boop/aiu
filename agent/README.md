# AIU 本地智能体

本目录实现一个通过 Ollama 本地 API 调用 `qwen3.5:4b` 的命令行智能体。它保留对话历史；需要计算时可以调用受限的算术工具，回答本地资料问题时可以读取项目 `knowledge/` 目录中的文本文件，也可以按用户明确要求新建、覆盖或删除其中的文件。

## 模块职责

- `__main__.py`：命令行入口，读取配置并组装客户端与智能体。
- `ollama_client.py`：调用 `http://127.0.0.1:11434/api/chat`。
- `runner.py`：管理对话历史和有上限的工具调用循环。
- `tools.py`：分发允许使用的计算器和知识文件工具。
- `knowledge.py`：在项目 `knowledge/` 目录内列出、读取、新建、覆盖和删除 `.md`、`.txt` 文件。

## 运行

先启动 Ollama，并确保本地已有 `qwen3.5:4b`，然后在 AIU 项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m agent
```

输入 `/clear` 清空对话，输入 `/exit` 退出。可用 `OLLAMA_MODEL` 和 `OLLAMA_BASE_URL` 环境变量更换模型或 API 地址。

## 本地知识文件问答

把 UTF-8 编码的 `.md` 或 `.txt` 文件直接放进项目根目录的 `knowledge/` 文件夹，然后在对话中询问文件内容，例如“根据示例资料，智能体目前有哪些能力？”。智能体会先列出文件，再读取相关文件回答，并显示工具调用记录。`knowledge/示例资料.md` 可用于首次试用。

文件操作仅限 `knowledge/` 目录的直接子文件；只允许 `.md`、`.txt`，单个文件最多 1 MB，给模型读取和写入的内容最多 12,000 个字符。新建、覆盖前会展示将写入的完整内容并要求输入 `CREATE 文件名` 或 `OVERWRITE 文件名`；删除前要求输入 `DELETE 文件名`。其他输入会取消操作。
