# STM32 工具下载与准备清单

电脑检查及整理日期：2026-10-07。

## 已有工具

- Keil µVision 5.14.1：已找到程序，但尚未确认 ARM 编译器与对应 STM32 支持包是否完整。
- STM32CubeProgrammer 2.16.0：已找到，可用于烧录。
- ST-Link WinUSB 驱动：已有安装记录。
- Git、uv、Python、Ollama、千问：已有。
- 本项目独立安装 pyserial 3.5，提供电脑与串口设备通信所需的 Python 库。

## 现在优先准备

| 工具 | 用途 | 官方网址 |
|---|---|---|
| STM32CubeIDE（Windows 64 位） | 官方 C/C++ 编辑、编译和调试环境；可选择它完成固件开发 | [官方下载](https://www.st.com/en/development-tools/stm32cubeide.html) |
| STM32CubeMX | 配置芯片引脚、时钟、串口并生成初始化工程 | [官方下载](https://www.st.com/en/development-tools/stm32cubemx.html) |
| Keil 芯片支持包（若继续使用 Keil） | 为具体 STM32 系列提供芯片支持，型号确定后选对应包 | [官方设备与支持包入口](https://www.keil.arm.com/devices/) |

STM32CubeIDE 与 Keil 是可选开发路线，不要求两个都安装。CubeMX 适合图形化配置；具体是否需要单独安装，取决于所选 IDE 版本及其配套流程。建议先准备 CubeIDE 和 CubeMX；已有的 CubeProgrammer 与 ST-Link 驱动不必重复安装。

## 后续部署板端模型再准备

- [X-CUBE-AI 官方页面](https://www.st.com/en/embedded-software/x-cube-ai.html)：模型转换与 STM32 集成工具入口，属于 ST Edge AI Suite。
- [STM32Cube AI Studio 官方使用说明](https://wiki.st.com/stm32mcu/wiki/AI:Creating_a_project_in_STM32Cube_AI_Studio)：新一代板端模型部署工具的流程说明。

点灯和 PID 参数通信不需要先安装板端 AI 工具。板端模型一般是小型神经网络，具体能否部署需要依据芯片与模型评估，不默认部署电脑上的千问。

## 根据硬件决定是否需要驱动

- ST-Link 驱动已找到，不必提前重复安装。
- USB 转串口的 CH340、CP210x 等驱动，等确认模块型号后再选对应厂家驱动。
- 普通 ST-Link/V2 不一定提供虚拟串口，开发板没有可用串口接口时可能需要 USB 转串口模块。

## 还需要确认

1. STM32 芯片与开发板型号。
2. 烧录器型号，开发板是否自带 ST-Link。
3. LED 引脚及亮灭电平。
4. 串口通信走板载虚拟串口还是 USB 转串口模块。
5. PID 阶段控制什么对象，有哪些传感器和执行器。

## 环境操作

桌面快捷方式打开项目文件夹；在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m host
```

此命令只列出串口，不烧录、不点灯，也不改变硬件状态。
