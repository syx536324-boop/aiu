# AIU4 模块结构

| 模块 | 责任 |
|---|---|
| src/main.mjs | 仅组装配置、模块和应用入口 |
| src/core | Pi Agent 运行、会话/事件持久化、单任务限制与停止 |
| src/providers | Pi AI 对接本地 Ollama |
| src/research | 官方目录/索引检索、文献库、PDF 收集、评阅卡、研究工具 |
| src/translation | 可选全文翻译插件、逐段配对、进度与译文缓存 |
| src/tools | 项目笔记的受限读写工具 |
| src/web | HTTP JSON API、静态页面、SSE |
| web | 页面结构、样式、交互状态与进度展示 |
| python | pypdf 按页文本、pdfminer.six 布局段落识别 |
| scripts 和根目录 ps1 | 依赖安装、启动、停止 |

## 前后端契约

GET `/api/status`、`papers`、`discovery`、`reviews`、`jobs`、`sessions`、`notes` 用于读取；POST `/api/discover`、`import`、`collect`、`chat`、`cancel` 执行用户动作。长任务立即返回 jobId，进度由 `/api/events` SSE 推送。

翻译插件：GET `/api/translations` 返回列表译文和全文状态；GET `/api/translation?id=ID&page=N` 返回三页原文/译文配对；GET `/api/bilingual-file?id=ID` 导出完成稿。POST `/api/translate` 接收 `{ids:[ID]}` 处理整篇可提取正文；POST `/api/translate-metadata` 接收 `{scope:"discover"|"papers",ids:[ID]}` 处理当前显示的标题/摘要。候选和原文来自后端已知文献，不接受任意网址。`web/translation.js` 管选择、配对展示和进度订阅，`src/translation/service.mjs` 管分批翻译、缓存和恢复，`src/providers/translator.mjs` 调用本机 Ollama。

检索、筛选、下载和持久化规则在后端。前端负责输入、展示、选择和订阅，不复制后端筛选算法。CLI 复用相同业务模块。

## 状态与资源

Pi 负责模型/工具往返；应用负责参数 schema、领域边界、工具结果、历史保存和任务生命周期。服务进程内单任务，防止多个长任务争抢本机资源；同一会话保留工具消息。模型回合上限 12、任务上限 600 秒，长会话提示新建，不伪装为无限记忆。

依赖版本由 npm 和 uv 锁文件固定。敏感和运行数据排除在 Git 外；模型 API 仅允许本机；网站仅绑定 127.0.0.1。下载只允许列明的开放论文源，并对重定向重新检查。PMLR 的官方 GitHub PDF 镜像限定在 mlresearch/v数字/main/assets 路径。

翻译单批不超过 6 个片段 / 2200 字符，长段落切片后再拼回原段落；仅当编号、数量和非空校验通过才保存该批译文。正文翻译全部可提取段落，阅读器分页不会缩小翻译范围；原文不经模型重写。全文任务最长 7200 秒、标题摘要任务最长 1800 秒，独立于研究对话默认 600 秒；均受同一个单任务调度器管理。取消后逐批缓存可用于续翻。

## 当前覆盖与限制

官方目录抓取不是全网搜索；目录布局改变时明确报错，不偷偷标“已核对”。元数据扩展可能限流并回退 Crossref，结果仍为待核验候选。按页提取不含 OCR，复杂公式/图表看原文。小模型的评阅不是同行评审，页码合法不等于结论被验证。
