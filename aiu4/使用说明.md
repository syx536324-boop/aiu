# 华小牛论文助手使用说明

## 1. 如何打开

双击桌面 **华小牛论文助手**。脚本启动本地服务、尝试启动已安装的 Ollama，然后打开 <http://127.0.0.1:8784/>。直接输入网址需要服务已经运行。

项目位置：`E:\aiu4`。没有配置开机自动启动。关闭网页不会停止后台；需要时运行 `stop-aiu4.ps1`，它仅停止本项目 Node 服务，保留其他项目可能共用的 Ollama。

## 2. 找论文

1. 进入 **在线找论文**，输入研究方向，例如“智能体”“目标检测”“diffusion”“reasoning”。
2. 选择起始年份，点击检索。在 **工作概览** 可以查看进度或停止。
3. 默认查 ICML 2025 与 NeurIPS 2025 官方主会目录，以及本项目基础目录；这不是全网搜索，也不包含所有最新年份。
4. 需要更多范围时勾选 **扩展公开元数据索引**。接口可能限流；平台返回的发表信息仍标“元数据待核对”。
5. 查看每篇的出处与待核验项，点击 **加入文献库**。

常见中文方向会映射为英文；复杂中文问题可放研究对话，让本地模型整理英文检索词。没有结果时先换成简短关键词。官方目录缓存 24 小时，扩展索引成功结果缓存 1 小时。

## 3. 收集和阅读

在 **我的文献库** 勾选 1—8 篇，点 **收集所选论文**。系统依次保存 PDF、按页 Markdown 和 BibTeX。遇到网络故障保留已完成结果，可再次点击重试。没有允许来源的开放 PDF 时明确报告失败，不绕过付费墙。

收集后点击 **阅读正文**；一次显示 3 页。公式、图表与复杂排版以原 PDF 为准。原文位于 `E:\aiu4\data\papers\论文ID\original.pdf`，可直接打开。

## 4. 用自然语言操作

在 **研究对话** 输入，例如：

> 帮我在线找 5 篇智能体相关的 ICML 或 NeurIPS 主会论文，说明出处、相关性和还需要核查的证据。先列候选，不要下载全部。

> 将候选中的第一篇加入文献库并下载，分批阅读方法和实验所在页，保存带页码的中文评阅卡。没核实的代码、数据和结论要说明。

> 对比文献库的 ReAct 和 LoRA，它们研究的问题有什么不同？引用读过的页码，保存中文笔记。

模型需要实际调用工具，下载/保存才会发生。进度和失败详情见概览；会话自动保存。长会话接近上下文上限时新建会话。小模型可能选错工具或解释不准，请打开来源和证据页核查。

默认对话名 `aiu4-research:latest` 复用本机 `qwen3.5:4b` 的权重，单独设置 16K 上下文以容纳论文；不改变 aiu 原有模型的配置，不重新训练。兼容接口使用 `reasoning_effort: none` 关闭冗长思考输出。若换模型，要同时确认该模型实际的 Ollama 上下文参数，而不只修改应用显示的 contextWindow。

## 5. 什么才算高质量

发表出处用于初筛；还要看研究问题、实验设计、强基线、消融、数据质量、复现条件和局限。本应用不会用一个虚构“质量分”代替这些证据。详见 `论文筛选标准.md`。

**论文评阅卡** 是模型根据所读页生成的草稿；页码合法不等于结论已经证明。需要人工核对事实与引文。没有阅读全文时必须写清实际读取范围。

## 6. 保存在哪里

| 内容 | E:\aiu4 下的位置 |
|---|---|
| 原始论文、正文、来源、校验和、引用 | data/papers/论文ID/ |
| 研究笔记、文献索引、评阅 Markdown | data/workspace/ |
| 结构化评阅卡 | data/reviews/ |
| 会话与任务、工具事件 | data/sessions/、data/jobs/、data/events.jsonl |
| 官方目录缓存与检索候选 | data/discovery/ |
| 服务日志 | logs/ |

这些内容默认不进 Git。源代码在 `src`、`web`、`python`，不会因为换个会话丢失论文文件。

## 7. 修改模型与端口

在 `E:\aiu4\.runtime\config.json` 写入需要覆盖的字段，例如：

```json
{"model":"aiu4-research:latest","port":8784}
```

先停止再启动。模型必须已经存在于 Ollama；本项目不会悄悄下载新模型。也支持环境变量 `AIU4_MODEL` 与 `AIU4_OLLAMA_URL`，模型地址限制本机。

## 8. 命令行方式

使用项目启动脚本可自动找到 Node。若终端的 PATH 已配置 Node，也可以：

```powershell
cd E:\aiu4
node src/main.mjs search "agent" 2022
node src/main.mjs list
node src/main.mjs collect react2023 lora2022
node src/main.mjs chat
```

在线结果先 `node src/main.mjs import 论文ID`，再 collect。`search "agent" 2022 --broad` 启用元数据扩展。

CLI 与网页共用数据目录，请避免同时执行写入任务；单任务限制针对网页服务进程。

## 9. 常见问题

- **网页打不开**：双击启动快捷方式；错误见 `logs/server.err.log`。端口被其他程序占用时更换端口。
- **检索有结果，对话不能用**：检索不需要模型；对话需要 Ollama 已启动且指定模型已安装。顶部状态会说明。
- **公共接口 429**：是限流，稍后重试或使用官方目录；界面不会把失败伪装成空白成功。
- **PDF 下载或提取失败**：勾选失败的论文，再点“收集选中文献”。连接失败会自动换用其他已核对的公开来源；重试优先使用上次未失败的来源。等待响应限 30 秒，PDF 传输限 180 秒，进度显示已接收大小。YOLO 已补充作者官网公开 PDF，正文会标明实际下载版本。详情保存在对应 metadata.json；扫描件需要额外 OCR，本版没有安装。
- **数据是否全部离线**：对话本地处理；在线检索和下载需要联网，关键词会发送给所选公开来源。

## 10. 翻译插件：可选逐段中英对照

“在线找论文”和“我的文献库”顶部都有 **阅读模式**，选择会记在当前浏览器中，两页共用：

- **不翻译 · 英文原文**：点击论文的“阅读英文原文”，读取原文；在线候选尚未收集时会先下载。此模式不调用翻译模型。
- **全文中英对照 · 每段保留原文**：点击某篇论文的“全文中英对照”，自动加入文献库（如需要）、下载并逐段翻译整篇可提取正文。附录和参考文献也包含在内，不只处理当前三页或摘要。阅读器按三页翻阅，翻译任务继续处理剩余全文。

文献库还可以勾选最多 8 篇，然后点 **翻译所选论文全部正文**。列表顶部的 **翻译本页标题/摘要** 只翻译当前显示结果的标题和已有摘要，按钮名称与全文入口区分；缺失的摘要不会编造。列表与正文都保留英文，并在相应段落下面显示中文。

阅读器内可随时切换模式；在“全文中英对照”模式点 **开始翻译全文 / 继续翻译全文**。翻译中可查看已完成段落，未完成的段落明确标记。切换为“不翻译”改变展示方式，正在运行的任务可到“工作概览”点击 **停止**。关闭阅读窗口不会中断后台任务。

全文翻译最长 2 小时，列表翻译最长 30 分钟；本机一次运行一个任务。中断、模型错误或时间用尽后，再点相同的全文入口继续已有进度。模型名称或 PDF 文件改变时会重新建立译文缓存。完成后可点击 **下载中英对照 .md**。

### 保存位置

- 正文与进度：`E:\aiu4\data\papers\论文ID\bilingual.json`
- 完成的逐段对照稿：同目录的 `bilingual.md`
- 段落原文：同目录的 `paragraphs.json`
- 列表标题摘要：`E:\aiu4\data\translations\meta-论文ID.json`

翻译复用现有 `aiu4-research:latest` 本地模型，无需创建翻译账号、提供密钥或下载另一套大模型。机器翻译需核对术语、数字和公式；段落由 PDF 布局识别，双栏与跨页段落可能拆开，图片中的文字没有 OCR。
