# YOLO 实时推理应用使用说明

## 快速启动

在桌面双击 **YOLO 实时推理应用** 快捷方式。脚本会在后台启动本机服务并打开浏览器到：

<http://127.0.0.1:8765/>

首次启动时 Python 需要加载 PyTorch 和 YOLO 权重，等几秒后再操作。如果浏览器未自动弹出，也可以手动打开上面的地址。

也可以通过 PowerShell 启动：

```powershell
cd D:\aiu2
.\.venv\Scripts\python.exe -m yolo_demo web
```

这个命令会在当前窗口显示日志；保持窗口开启，服务才能工作。按 Ctrl+C 关闭服务。

## 网页操作

1. 在“模型权重”选择 COCO8 演示训练权重或 YOLO11n 预训练权重。
2. 选择摄像头编号，默认 0。若无画面，再尝试 1；同时检查 Windows 设置中的相机权限，并关闭占用摄像头的应用。
3. 调整置信度阈值：较低时保留更多候选框，较高时筛选更严格。
4. 点击“启动实时检测”。第一次加载权重可能需要数秒；成功后网页会显示带检测框的实时画面、帧率和设备信息。
5. 点击“停止检测”停止推理并释放摄像头。

启动后，页面由本机 Python 服务提供，地址绑定 `127.0.0.1`；摄像头画面在本机处理，不发送到云端。关闭浏览器标签不会自动关掉隐藏的服务进程。要停止服务，可在 PowerShell 执行：

```powershell
Invoke-RestMethod -Method Post http://127.0.0.1:8765/api/shutdown
```

如果网页显示无法连接，可重新双击快捷方式；若提示端口已占用，手动运行启动命令查看具体错误。

## 当前模型能识别什么

当前的 `best.pt` 是从 YOLO11n 预训练权重出发，在 COCO8 小样本示例上训练 3 轮所得。它主要用于验证摄像头推理链路，不是对你自己的物品或业务类别训练的模型。若要识别指定目标，需准备对应图片和边界框标注，再训练并选择新生成的权重。

网页也可切换到原始 `models\yolo11n.pt` 预训练权重。检测类别来自其训练数据集，并不因切换而自动变成自定义类别。

## 训练和单张图片预测

训练 COCO8 示例：

```powershell
cd D:\aiu2
.\.venv\Scripts\python.exe -m yolo_demo train
```

对图片推理：

```powershell
cd D:\aiu2
.\.venv\Scripts\python.exe -m yolo_demo predict --source "D:\照片\示例.jpg"
```

训练会更新并保存模型参数；预测和摄像头实时推理只使用模型参数，不会自行训练。训练产物默认是 `runs\coco8_train\weights\best.pt`。

## 项目结构与接口

- `yolo_demo/services/live_inference.py`：摄像头、YOLO 推理和帧状态。
- `yolo_demo/web/server.py`：前端静态资源、REST 接口和 MJPEG 视频流。
- `yolo_demo/web/static/`：网页 UI 与交互逻辑。
- `yolo_demo/__main__.py`：组合 train、predict、web 命令。

接口包括 `GET /api/config`、`GET /api/status`、`POST /api/start`、`POST /api/stop`、`POST /api/shutdown` 和 `GET /api/stream`。前端只调用本机 API；摄像头和模型计算由 Python 后端负责。

## GPU/CPU 自动切换

现在点击启动实时检测即可自动选择设备。显存占用达到85%或剩余不足1.5GB时转CPU；GPU利用率持续15秒达到90%时也转CPU。负载和显存连续恢复30秒后切回GPU。页面显示当前设备与原因；完整说明见 自动设备切换说明.md。
